# Free SEO setup for dzsscoutgroup.eu.org

This project is configured for the canonical site URL:
https://dzsscoutgroup.eu.org/

## Files added

- `robots.txt` — allows normal crawling and points crawlers to the sitemap.
- `sitemap.xml` — lists the public homepage.
- `CNAME` — keeps GitHub Pages pointed at `dzsscoutgroup.eu.org`.
- `index.html` — improved title, description, canonical URL, social metadata, and Organization structured data.

## Important

SEO changes can improve discovery, but no site can guarantee first place in Google. Ranking depends on many signals and changes over time.

## Google Search Console

1. Open Google Search Console: https://search.google.com/search-console/
2. Add `https://dzsscoutgroup.eu.org/` as a URL-prefix property, or add the domain property `dzsscoutgroup.eu.org` if you can verify it in DNS.
3. Verify ownership.
4. Open **Sitemaps** and submit:
   `https://dzsscoutgroup.eu.org/sitemap.xml`
5. Open **URL Inspection** and inspect:
   `https://dzsscoutgroup.eu.org/`
6. Use **Request indexing** after the latest deployment.

## Bing Webmaster Tools

1. Add `https://dzsscoutgroup.eu.org/` in Bing Webmaster Tools.
2. Verify ownership.
3. Submit `https://dzsscoutgroup.eu.org/sitemap.xml`.
4. Optionally configure IndexNow for future URL/content changes.

## Ongoing work that helps search visibility

- Keep the organization name and DZS/DZSSG abbreviations consistent on the homepage.
- Publish useful, original public content about the Scout Group, its activities, leadership, events, and resources.
- Keep important public pages crawlable without login.
- Keep the canonical URL as `https://dzsscoutgroup.eu.org/`.
- Check Search Console for indexing errors and search queries, then improve pages based on what visitors actually search for.

## Do not keyword-stuff

Do not add hidden blocks containing hundreds of repeated search terms. Use the official name and common abbreviations naturally in visible content.
